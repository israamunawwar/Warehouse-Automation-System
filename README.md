# نظام إدارة المستودع الذكي

تطبيق سطح مكتب (Tkinter + SQL Server) لإدارة مواد المستودع وسحبها وحجزها وإرجاعها من قبل المدربين.

## المتطلبات
- Python 3.10+ مع Tkinter
- SQL Server وبرنامج تشغيل ODBC (مثل «ODBC Driver 17 for SQL Server»)

## التثبيت
```
pip install -r requirements.txt
copy config.example.ini config.ini      # ثم عدّل اسم الخادم
```

## قاعدة البيانات
- قاعدة جديدة: نفّذ `DB.sql` ثم (اختياريًا) `insert info.sql` للبيانات التجريبية.
- قاعدة قديمة موجودة: خذ نسخة احتياطية ثم نفّذ `migration_01.sql` (آمن لإعادة التشغيل).

## التشغيل
```
python main.py
```
- إن لم يوجد أي مستخدم، يعمل التطبيق بدون تسجيل دخول؛ أنشئ مديرًا من تبويب «المستخدمون» ليُفعَّل الدخول لاحقًا.
- الأدوار: `admin` (كل الصلاحيات) و`viewer` (عرض المخزن والتقارير فقط).

## قواعد العمل
- **حجز:** يقلل «المتاح» ولا يغيّر الكمية في المخزن، ولا يمكن حجز أكثر من المتاح.
- **سحب:** يخصم من المخزن، ويستهلك أولًا حجز المدرب نفسه، ولا يسمح بأخذ ما حجزه غيره.
- **إرجاع:** يعيد الكمية، وبحد أقصى ما سحبه المدرب ولم يُرجعه.
- **حذف مادة/مدرب:** حذف ناعم (يبقى السجل التاريخي محفوظًا).

## الاختبارات
```
pytest
```
تغطي الاختبارات التحقق من المدخلات وقواعد الحجز/السحب/الإرجاع (بقاعدة وهمية) والتصدير وسلسلة الاتصال.

## الإعدادات
`config.ini` أو متغيرات البيئة: `WAREHOUSE_DB_SERVER`, `WAREHOUSE_DB_NAME`, `WAREHOUSE_DB_USER`, `WAREHOUSE_DB_PASSWORD`.
خط PDF العربي يُكتشف تلقائيًا من خطوط ويندوز، أو حدده عبر `WAREHOUSE_PDF_FONT`.
